Uploading to Microsoft 365

  1. In the Teams Developer Portal, register the API Management subscription key under Tools → API key registration, using the API Management base URL, and copy the auth config id.
  2. Paste that id above and download the package so the plugin uses it.
  3. Go to Apps → Import app, upload the .zip, then Preview in Teams to sideload the declarative agent.
  4. Open Microsoft 365 Copilot, pick the agent, and ask one of the sample questions.
