# Caldova Fabric APIM stack (Bicep)

This subscription-scoped deployment adds two delegated OAuth REST APIs and two generated MCP APIs to the existing `config.apim` service. It also creates or reuses the Caldova-side `privatelink.azurewebsites.net` zone, writes broker and broker SCM A records, and links the existing APIM VNet.

The template reads `../../config/deployment.json`. It does not create or modify the APIM service, its VNet, the broker, Entra registrations, role assignments, private endpoints, or cross-tenant peerings.

## Security contract

- The REST APIs do not require APIM subscription keys. The inbound policy removes both subscription-key forms before forwarding.
- APIM validates a signed, unexpired delegated token from the Fabric resource tenant. It requires the configured audience, `tid`, delegated `scp`, connector `azp`, and Fabric guest `oid`; app tokens are rejected.
- APIM saves the user bearer assertion, replaces `Authorization` with a system-assigned managed-identity token for `api://<brokerAudience>`, and forwards only to the fixed private broker origin.
- The broker must be configured with the APIM principal ID and must require the configured application role. The broker performs that independent caller-token and role validation before accepting `x-user-assertion`.
- Per-user throttling uses the verified `oid`. Correlation IDs are generated by APIM. Responses are marked `no-store`; this stack defines no cache policies.
- Optional Application Insights diagnostics record zero request and response body bytes and no headers. Verify any service-wide APIM diagnostic also has frontend response-body logging set to zero, because global diagnostics are outside this module.

No secret is accepted or emitted by this module. Client IDs, object IDs, role names, hostnames, and private IPs are configuration, not credentials.

## Required generated values

Create a deployment parameter file from `main.parameters.json.example` and replace every `REPLACE-*` value. The resource API client ID, broker audience, connector client-ID list, allowed Fabric guest object-ID list, broker private URL, and broker private endpoint IPv4 address are required. Bicep parameter constraints reject empty IDs, empty allowlists, an empty URL, and an empty or non-IPv4-length address.

Set `applicationInsightsName` only when that component already exists in the Caldova subscription. Leave it empty to omit the logger and all four API diagnostics. Set its resource group only when it differs from `config.apim.resourceGroup`.

The default creates `privatelink.azurewebsites.net` in the APIM resource group. To reuse an existing zone, set `createPrivateDnsZone` to `false`; set `privateDnsZoneResourceGroupName` only if the zone is in another Caldova resource group.

## Validate

```powershell
az bicep build --file fabric/bicep/apim/main.bicep
az bicep lint --file fabric/bicep/apim/main.bicep
```

## Preview and deploy

Authenticate to the APIM tenant and select the APIM subscription from `fabric/config/deployment.json` before running a subscription deployment:

```powershell
az login --tenant 12a4b86b-e64c-43f9-af05-d9130a72dfd2
az account set --subscription cf824570-a8ba-497a-a184-0a52f1830aa9
az deployment sub what-if --location westus2 --template-file fabric/bicep/apim/main.bicep --parameters @fabric/bicep/apim/main.parameters.json
az deployment sub create --location westus2 --template-file fabric/bicep/apim/main.bicep --parameters @fabric/bicep/apim/main.parameters.json
```

Deploy only after the APIM system-assigned identity has the configured broker application role and the broker has the matching `APIM_PRINCIPAL_ID`, audience, role, connector IDs, and Fabric guest IDs.

## Cross-tenant networking

This module intentionally does not create cross-tenant VNet peering. Create the APIM-to-broker peering in the Caldova tenant stage and the broker-to-APIM peering in the Fabric tenant stage. Both stages must use the corresponding remote VNet resource ID and enable virtual-network access; apply any required forwarded-traffic settings there. DNS alone does not provide network reachability.
